How Docify preserves your template

  1. The source PDF is analyzed and its exact HTML structure is saved as a skeleton — every label, column header, and currency symbol captured literally.
  2. Your variable content is matched to the skeleton's placeholder slots.
  3. The skeleton is filled with your values. Structure never changes.
  4. Playwright renders the final PDF pixel-perfectly.
What to provide: only the fields that differ from the original (amounts, client name, date, quantities). Everything else comes from the template.
Currency tip: always specify the currency code (XAF, EUR, USD…) in your content to avoid any ambiguity.
